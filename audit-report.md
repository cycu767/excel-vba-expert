# VBA audit report template

## Scope and evidence
Project/copy identity, files actually inspected, missing .frx/binaries, encoding,
Excel build/bitness, permissions, exclusions and business invariants.

## Findings
| ID | Severity / confidence | File / procedure / line | Evidence | Impact | Minimal correction | Regression test |
|---|---|---|---|---|---|---|

Do not invent findings to fill the table. Separate confirmed defects from hypotheses.

## Change plan
Ordered small patches, affected callers, authorization needed, rollback/checkpoints.

## Tests
Actual commands, fixtures, outcomes and evidence levels. Mark unexecuted tests NOT_RUN.

## Unresolved areas
Dynamic calls, resources, versions and production risks still requiring evidence.
